# 🚀 Abhishek Rai — 3D Full-Stack Developer Portfolio

A modern, high-performance **3D developer portfolio website** built with **React**, **TypeScript**, **Three.js**, **GSAP**, and **Vite**.

## ✨ Highlights

- **Interactive 3D / WebGL Character** powered by **Three.js & React Three Fiber**
- **Smooth Scroll & Animations** with **GSAP ScrollTrigger & Lenis**
- **AI-Generated Technical Blog Engine** with custom architectural vector diagrams
- **Built-in 3-Level AI Chess Game** (`/play`) powered by Alpha-Beta pruning & positional evaluation
- **Responsive Design** across desktop, tablet, and mobile

---

## 🧰 Tech Stack

- **Frontend:** React.js, TypeScript, Three.js / R3F, GSAP, Lenis, Vite
- **Core Expertise Featured:** Next.js, React Native, NestJS, Node.js, PostgreSQL, MongoDB, Redis, Docker

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
